Карта плотности населения Республики Бурятия по районам
Задача
Визуализировать распределение плотности населения по административным районам Республики Бурятия.

Данные
Границы районов: OpenStreetMap (через QuickOSM).

Данные о населении: Росстат.

Площадь районов: рассчитана в QGIS через $area.

Инструменты
QGIS 4.2

QuickOSM (загрузка границ)

Присоединение таблицы (Join) по полю с названием района

Калькулятор полей для расчёта плотности

Градуированная символика (Graduated)

Print Layout

Результат
Карта плотности населения с цветовой шкалой по районам.

Легенда с интервалами плотности (чел./км²).

Подписи районных центров

Экспорт: PDF и PNG (300 dpi).
